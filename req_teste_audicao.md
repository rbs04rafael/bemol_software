Área de “teste de audição”. Nessa área, o usuário deverá informar qual tipo de instrumento ele deseja usar para testar a sua audição. Inicialmente vamos trabalhar com alguns tipos de instrumentos: saxofone alto, flauta transversal, trompete, trombone e teclado. Após selecionar o instrumento, o usuário deverá informar o nível de dificuldade que deseja para o teste de audição. Nessa etapa inicial, haverá apenas três tipos de dificuldade: básico, intermediário e avançado.

 No nível básico, o instrumento deverá emitir um som de uma de suas notas aleatoriamente. A nota será uma mínima (2 tempos).

No nível intermediário, o instrumento deverá emitir o som de duas notas aleatoriamente. A nota será uma semínima (1 tempo).

No nível avançado, o instrumento deverá emitir um som de três de suas notas aleatoriamente. A nota será uma colcheia (1/2 tempo).

Após emitir o som da(s) nota(s), o sistema deverá exibir todas as notas que aquele instrumento é capaz de emitir e o usuário deverá selecionar aquelas que ele pensa ser as que foram emitidas. Após essa seleção, o sistema deverá analisar a resposta do usuário e dizer se ele acertou ou erro. Em caso de erro, deverá dizer quais notas ele errou e mostrar a diferença sonora entre as notas corretas e as erradas que foram escolhidas pelo usuário.

O sistema deverá permitir ao usuário realizar uma nova roda de teste mesmo que não tenha respondido a etapa atual. Também deverá permitir ao usuário ouvir no máximo 3 vezes o som emitido pelo instrumento. 

Além disso, o sistema deverá ser capaz de fornecer o seguinte mecanismo de ajuda: deverá ser eliminada algumas das notas que estão disponíveis para o usuário selecionar.
